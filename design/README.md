# Design

Mockups for the Frigate NVR iOS app (iPhone, 390 x 844).

Live canvas: https://claude.ai/artifact/B1Kmx3q1oE8G78kJG5FMVj

`mockups/` holds the source of each screen (`*.dc.html`) and the canvas layout (`canvas.json`).

| Screen | File |
| --- | --- |
| Servers (list, switch, add) | `Servers.dc.html` |
| Add server | `Connect.dc.html` |
| Live (camera grid per server) | `Main.dc.html` |
| Camera live view | `Camera.dc.html` |
| Review (alerts, detections, motion across servers) | `Review.dc.html` |
| Event detail | `Event.dc.html` |
| History overview (all cameras, activity per day) | `HistoryOverview.dc.html` |
| Playback per camera: player + Events / Timeline switch | `History.dc.html` |
| Playback, timeline state (motion wave) | `History-Timeline.dc.html` |
